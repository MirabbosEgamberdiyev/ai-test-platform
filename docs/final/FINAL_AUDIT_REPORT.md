## 1. Executive Summary & Product Mission

The enterprise platform located at `D:\My-project\ai-test-platform` has been comprehensively transformed and verified as a production-grade **Universal AI Web Testing Platform**.

The platform enables ordinary business and QA users—without programming, DOM, CSS selector, XPath, or test automation knowledge—to test virtually any authorized website using natural language instructions.

### Core Architectural Guarantees:
1. **Target Technology Independence:** Operates purely through the browser interface (Playwright Chromium sandbox). Target websites built with **React, Next.js, Vue, Angular, Svelte, PHP, Laravel, WordPress, Java/Spring Boot, Python/Django/Flask, ASP.NET, Go, or static HTML5** are seamlessly discovered, tested, and analyzed with zero source code access requirements.
2. **Zero-Bypass Examination Ethics:** Proctored testing systems, bot evasion techniques, and unauthorized automated examination taking are strictly prohibited and hard-blocked at the domain policy level.
3. **SSRF Guard & Vault Security:** Complete mitigation against Server-Side Request Forgery (blocking private subnets RFC 1918, localhost loopbacks `127.0.0.1`, cloud metadata `169.254.169.254`, and non-HTTP schemes). Credentials are encrypted with AES-256-GCM.
4. **Natural Language in 4 Languages:** Native prompt understanding, test case generation, and defect explanations across **Uzbek Latin (`uz-Latn`), Uzbek Cyrillic (`uz-Cyrl`), Russian (`ru`), and English (`en`)**.
5. **Human-in-the-Loop Approval:** Test plans generated by AI are presented in an intuitive UI for review and explicit approval prior to headless browser execution.
6. **Multi-Format Exportability:** Standalone HTML, JSON, and CSV export capabilities alongside live browser execution logs and screenshot evidence.
